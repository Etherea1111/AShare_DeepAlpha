## Version_1.4.261113

- **更新日期：** 2026-11-13
- **更新类型：** 因子 IC 稳定性、分年度表现与冗余分析
- **对应内容：** 在 `Version_1.3.261111` 的总收益复权因子上补充因子层面的截面预测能力审计。

### 主要修改

1. **新增因子稳定性脚本。** 新增 `scripts/analyze_factor_stability.py`，分别读取训练集和验证集因子标签文件，计算各因子与未来 5/20 日收益的逐日截面 Spearman RankIC。
2. **重叠标签显著性。** 使用 `horizon - 1` 阶 Newey-West HAC 滞后估计均值 RankIC 的 t 统计量和双侧 p 值，并输出 ICIR、年化 ICIR 与正 IC 比例。
3. **分年度与冗余分析。** 输出 2019 至 2023 年的分年度 IC；同时对 21 个特征两两计算逐日截面 Spearman 相关性，识别信息重复。
4. **截面无变化处理。** `market_return_1` 和 `market_breadth_up` 在同一交易日对所有股票相同，无法计算截面 RankIC，统一标记为 `no_cross_sectional_variation`，不纳入符号一致性比较。
5. **测试与文档。** 新增 RankIC、Newey-West、分年度汇总和产物写出测试；README 与阶段报告同步更新。

## Version_1.1.261008

- **更新日期：** 2026-10-08
- **更新类型：** 项目缺陷审查与版本日志建立
- **对应内容：** 对 `Version_1.0.260930` 所包含的代码、数据产物、测试和阶段报告进行了复核。
- **新增文件：** `reports/版本更新日志.md`

### 本次审查确认的主要问题

1. **点时成分股流程不能识别退出事件。** 当前快照文件只保存每周快照中的正向成员；股票从后续快照消失时，没有生成移除事件，点时面板仍可能沿用最近一次成员记录。
2. **历史行情源头仍存在幸存者偏差。** 日行情下载基于当前行业成分股，再回取其历史行情。后续点时过滤无法恢复从未下载的历史退市或调出行业股票。
3. **因子和标签使用未复权价格。** 分红、送转等公司行为可能制造非真实收益跳变，影响动量、波动率和前瞻收益标签。
4. **尚未形成可交易回测。** 当前结果只有重叠标签上的 RankIC 和分组收益差，尚未模拟交易成本、滑点、T+1、停牌、涨跌停、换手和成交约束。
5. **KNN 无 NumPy 回退路径未接入模型选择。** `predict_knn()` 虽然包含标准库实现，但交叉验证仅在 NumPy 可用时加入 KNN 候选；当前无 NumPy 环境下无法复现已有 KNN 报告。
6. **方向模型指标口径不一致。** 逻辑回归输出上涨概率，却同时被送入连续收益的 MAE/RMSE 评价，相关数值不具备清晰的金融解释。
7. **版本产物存在记录差异。** 阶段报告中的部分验证指标与当前 `model_baseline_report.json` 不一致，需在后续重跑后统一报告和数据产物。
8. **复现环境未锁定。** 项目缺少 `requirements.txt`、`pyproject.toml` 或环境文件；部分 JSON 报告包含本机绝对路径，跨机器复现不完整。

### 本次验证

- `python3 -m unittest discover -s tests -v`：15 项测试全部通过。
- `python3 -m compileall -q scripts tests`：通过。
- `git diff --check`：通过。
- 对点时成员退出场景进行了额外行为检查，确认当前实现会保留退出前的成员状态。

本版本只新增审查记录和版本日志，没有宣称上述问题已经修复。后续模型结论仍应视为研究原型结果，不应直接用于实盘决策。
