# 数据字段对照表

## 日频行情数据 `j66_money_finance_daily_2018_2024.csv`

| 字段名 | 中文含义 |
| --- | --- |
| `date` | 交易日期 |
| `code` | 股票代码 |
| `code_name` | 股票名称 |
| `industry_code` | 行业代码 |
| `industry_name` | 行业名称 |
| `open` | 开盘价 |
| `high` | 最高价 |
| `low` | 最低价 |
| `close` | 收盘价 |
| `preclose` | 前收盘价 |
| `volume` | 成交量 |
| `amount` | 成交额 |
| `turn` | 换手率 |
| `pctChg` | 涨跌幅（百分比） |
| `tradestatus` | 交易状态 |
| `isST` | 是否为 ST 股票 |
| `adjustflag` | 复权标识 |
| `adjustment` | 复权方式 |
| `data_source` | 数据来源 |

## 股票池成分数据 `j66_money_finance_constituents.csv`

| 字段名 | 中文含义 |
| --- | --- |
| `code` | 股票代码 |
| `code_name` | 股票名称 |
| `industry_code` | 行业代码 |

## 历史点时成员快照 `j66_money_finance_constituent_snapshots_2018_2024.csv`

| 字段名 | 中文含义 |
| --- | --- |
| `snapshot_date` | 快照查询日期 |
| `effective_date` | 成员信息在该快照中的可用日期 |
| `code` | 股票代码 |
| `code_name` | 股票名称 |
| `industry_code` | 行业代码 |
| `industry_name` | 行业名称 |
| `classification` | 行业分类标准 |
| `source_update_date` | 数据源记录的分类更新日期 |
| `source` | 来源接口或生成方式 |

## 点时行情面板附加字段

| 字段名 | 中文含义 |
| --- | --- |
| `membership_asof_date` | 行情日期对应的成员查询日期 |
| `membership_snapshot_date` | 实际使用的成员快照日期 |
| `membership_effective_date` | 成员事件生效日期 |
| `membership_event_type` | 事件类型：`member` 或 `removed` |
| `membership_source` | 成员事件来源 |
| `point_in_time_member` | 是否为该时点成员 |
