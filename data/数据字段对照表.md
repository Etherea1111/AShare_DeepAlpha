# 数据字段对照表

## 日频行情数据 `j66_money_finance_daily_2018_2024.csv`

| 字段名 | 中文含义 |
| --- | --- |
| `date` | 交易日期 |
| `code` | 股票代码 |
| `code_name` | 股票名称 |
| `industry_code` | 行业代码 |
| `industry_name` | 行业名称 |
| `open` | 开盘价 |
| `high` | 最高价 |
| `low` | 最低价 |
| `close` | 收盘价 |
| `preclose` | 前收盘价 |
| `volume` | 成交量 |
| `amount` | 成交额 |
| `turn` | 换手率 |
| `pctChg` | 涨跌幅（百分比） |
| `tradestatus` | 交易状态 |
| `isST` | 是否为 ST 股票 |
| `adjustflag` | 复权标识 |
| `adjustment` | 复权方式 |
| `data_source` | 数据来源 |
